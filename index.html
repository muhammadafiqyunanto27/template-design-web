Cara Deploy ke Vercel

1. Buka Vercel Import → pilih repo muhammadafiqyunanto27/template-design-web
2. Saat muncul daftar folder, pilih salah satu dari 4 halaman induk di atas (atau template langsung)
3. Setiap template folder adalah project mandiri — deploy satu per satu
4. Salin URL hasil deploy dan paste ke halaman induk yang sesuai

Open GitHub Repository

🏠 Halaman Induk (5 total)

1 Home + 4 halaman varian (Next.js Intl, Next.js ID, Astro Intl, Astro ID). Setiap varian berisi 10 template.

🇮🇩 Indonesia Variants

Setiap template punya versi -id dengan Bahasa Indonesia, IDR currency, +62 WhatsApp, BPOM/Halal/Kominfo/OJK, dan pembayaran lokal (GoPay, OVO, DANA, ShopeePay, VA, QRIS, COD).

🎨 No AI Slop

Zero purple gradients. Max 1 subtle gradient per template. Semantic color tokens. WCAG AA contrast.

Total: 1 home + 4 induk + 40 project template = 45 deployment di Vercel.
