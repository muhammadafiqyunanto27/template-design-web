Ready to Deploy?

Each template is a standalone project. Click any template folder in the GitHub repo, then use Vercel Import or Netlify Deploy directly from that folder.

Open GitHub Repository

🇮🇩 Indonesia Variants

Every template has an -id version with Bahasa Indonesia, IDR currency, +62 phone/WhatsApp, BPOM/Halal/Kominfo/OJK badges, and local payment methods (GoPay, OVO, DANA, ShopeePay, VA, QRIS, COD).

🎨 No AI Slop

Zero purple gradients. Max 1 subtle gradient per template. Semantic color tokens. WCAG AA contrast. Dark mode where appropriate.

⚡ Two Frameworks

Each template has both Next.js (App Router) and Astro implementations. Pick the one that fits your stack.

Deploy any template folder individually to Vercel — each is a complete, independent Next.js or Astro project.
